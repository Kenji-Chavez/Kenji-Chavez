### 🌋 Análisis de Demanda Sísmica en el Perú — Python & Power BI

Pipeline ETL desarrollado para **procesar, depurar y analizar registros sísmicos del Instituto Geofísico del Perú (IGP)**.

- Procesamiento de datos con **Python, Pandas y NumPy**.
- Transformación y preparación de datos mediante **Power Query**.
- Cálculo de la **PGA resultante** a partir de componentes de aceleración.
- Dashboard interactivo desarrollado en **Power BI y DAX**.
- Identificación de una aceleración máxima de **514.49 cm/s²** en la estación Lurín, Lima, durante el evento del 22 de junio de 2021.
- Análisis orientado a generar información útil para la **prevención y gestión del riesgo sísmico**.

🔗 **[Ver proyecto en GitHub](https://github.com/Kenji-Chavez/Analisis-Demanda-Sismica-Peru-IGP)**
